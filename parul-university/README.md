# Parul University & EduSphere Academic Portal

Official university academic portal featuring 360° virtual campus tours, Supabase student authentication, admission portal, and admin dashboard.

## Features
- **360° Virtual Campus Tour**: High-resolution interactive virtual campus viewer
- **Authentication & Database**: Supabase auth integration with email/password and Google login
- **Student Dashboard**: Real-time profile management, session tracking, and user details
- **Admin Command Center**: Complete administrative overview and student inquiry management

## Deployment
Deploy to Vercel or Netlify pointing to this folder:
- **Root Directory**: `parul-university`
- **Publish Directory**: `.`
