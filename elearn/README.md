# EduSphere — College E-Learning Platform

A premium, fully responsive college e-learning website built with pure HTML, CSS, and JavaScript.

## Features
- 🌑 Dark mode with animated gradient orbs
- 📚 Course catalogue with category filters
- 🎓 Faculty profiles with follow functionality
- 💬 Auto-scrolling testimonials carousel
- 📝 Signup modal with form validation
- 📱 Fully responsive (mobile-first)
- ✨ Scroll reveal animations & stat counters

## Tech Stack
- HTML5 (semantic)
- Vanilla CSS (glassmorphism, CSS variables, animations)
- Vanilla JavaScript (ES6+, IntersectionObserver)

## Deployment
Deployed on Netlify. Configured via `netlify.toml`.
