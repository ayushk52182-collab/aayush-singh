# Aayush Shop — Premium E-Commerce Store

An elegant, high-performance curated e-commerce destination engineered by Aayush Singh.

## Features
- **Curated Catalog**: Electronics, Fashion, Home Decor, Perfumes, Books & Luxury Watches
- **Interactive Cart System**: Real-time cart calculations, coupon discount engine (`AAYUSH20`)
- **Aayush Prime Membership**: 1-click free trial membership flow with perks
- **Responsive Layout**: Mobile-first luxury shopping experience

## Deployment
Deploy directly to Vercel or Netlify pointing to this folder:
- **Root Directory**: `aayush-shop`
- **Publish Directory**: `.`
